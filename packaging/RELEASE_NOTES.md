**MOCHI ARCADE 0.1.0** — first release! Five original retro mini games starring the mochi gang.

### Install
```sh
curl -fsSL https://raw.githubusercontent.com/neuralfoundry-coder/mochi-arcade/main/install.sh | sh
```
or `sudo apt install ./mochi-arcade_0.1.0_all.deb` (Debian/Ubuntu) · `pip install mochi-arcade-0.1.0.tar.gz` (anywhere with Python 3.8+).

### Games
- **Soap Hop** — bubble-trapping single-screen platformer (8 stages)
- **Jelly Stack** — falling-block puzzle with wobbly jellies (Marathon / Sprint 40 / Endless)
- **Comet Kitty** — fixed-screen space shooter with formations, dives, wingman stars and bonus parades
- **Noodle Slurp** — snake with golden dumplings and mazes
- **Bounce Bun** — brick breaker with snack bricks and power-up capsules

Profiles with saved settings, high-score tables and per-game options. Chiptune music and sound effects are synthesized at run time; all art is drawn from code. Runs on desktops and directly on a Linux text console (KMS/DRM) — tested at a steady 60 fps on a 2015 MacBook Pro running Ubuntu Server 24.04.
